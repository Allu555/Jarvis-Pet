#   pip install -r requirements.txt

# Windows-specific pre-steps (before pip install):
#   1. Install ffmpeg and add to PATH:
#        winget install Gyan.FFmpeg
#      OR download from https://ffmpeg.org/download.html and add bin/ to PATH
#
#   2. Install PortAudio (needed by PyAudio):
#        pip install pipwin
#        pipwin install pyaudio
#      OR download the .whl from https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio
#        pip install PyAudio‑0.2.14‑cp311‑cp311‑win_amd64.whl
#
#   3. (Optional) Install nircmd for precise volume control:
#        Download from https://www.nirsoft.net/utils/nircmd.html
#        Copy nircmd.exe to C:\Windows\System32\ or any PATH directory
#
#   4. (Optional) Install CUDA toolkit if you have an NVIDIA GPU
#      to enable faster Whisper transcription (WHISPER_DEVICE = "cuda").
